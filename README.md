Realização do Projeto Integrador Final da Matéria de Fundamentos de Software ministrada pela professora Sabine Cassol na UEPG.

# Projeto Integrador — Fundamentos de Engenharia de Software

## Nome do sistema
Sistema de Gerenciamento de uma Rede de Academias

## Objetivo
Propor uma solução de software para automatizar o controle de planos de mensalidades, centralizar agendas de instrutores e salas, e disponibilizar acompanhamento de treinos, avaliações físicas e acesso à academia.

## Integrantes
- Leonardo Nogueira Martins — GitHub: @Leozi0

## Funcionalidades principais
- Cadastro e gerenciamento de alunos, instrutores e funcionários
- Controle de planos de mensalidade e status de acesso (liberado/bloqueado)
- Agendamento de horários individuais e modalidades coletivas
- Criação e consulta de avaliações físicas e fichas de treino
- Emissão de relatórios financeiros e de captação de clientes
